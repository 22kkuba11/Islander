# ISLANDER

22kkuba11.github.io/Islander

A simple 2D survival game made with **Godot 3.6**.

## Features

- 8-directional movement
- Resource gathering
- Wood, stone and iron
- Crafting system
- Stone pickaxe required to mine iron
- Automatic enemy combat
- Customizable settings
- Optional music

## Requirements

- Godot 3.6
- Windows, Linux or HTML5 build

## Installation

1. Download the latest release.
2. Extract the downloaded archive.
3. Run the game.

## Controls

| Key | Action |
|---|---|
| WASD / Arrow Keys | Move |
| E | Collect resources |
| C | Craft stone pickaxe |
| ESC | Pause / Settings |
